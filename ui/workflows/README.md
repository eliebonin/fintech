# UI workflows

Workflows capture journeys that cross screens and services. Start with:

- external identifier mapping exception to verified canonical listing;
- instrument proposal to approved effective definition version;
- trade booking to correction/cancellation event;
- market-data selection to reproducible valuation mark; and
- position/cash input to Soft-NAV review and approval.

Each workflow should state actor, tenant, preconditions, allowed transitions,
API calls, audit evidence, and recovery path when a central lookup or tenant
write cannot complete.
